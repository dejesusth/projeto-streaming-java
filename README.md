# Projeto Streaming Java

Sistema de streaming desenvolvido em Java utilizando Programação Orientada a Objetos para a disciplina de Programação de Aplicativos

## Funcionalidades

- Cadastro de conteúdos
- Reprodução de conteúdos
- Gerenciamento de favoritos
- Exibição de detalhes
- Catálogo de conteúdos

## Tecnologias utilizadas

- Java
- IntelliJ IDEA
- Git e GitHub
- UML (draw.io)

## Conceitos de POO aplicados

- Abstração
- Encapsulamento
- Herança
- Polimorfismo
